# 开发与测试

## 构建

从 README 完成本地依赖与 `.env` 配置后：

```powershell
# 仅编译及打包，不连接业务数据库执行测试
./scripts/Maven.ps1 package -DskipTests -B -ntp
npm run build
# 开发网页
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
# 预览已构建网页
npm run preview -- --port 4173 --strictPort
```

`Build.ps1` 会先执行 Maven verify（含数据库集成测试），再构建网页。因此普通本地业务环境使用上面的跳过测试打包命令；执行完整验证前配置独立测试库。

## 浏览器隔离回归

先运行 Vite 开发服务和本机 Microsoft Edge，再执行：

```powershell
npm run test:ui
npm run test:sync
npm run test:cache
```

脚本通过 Playwright 拦截业务 API，使用浏览器内测试数据，不创建业务账号或任务。缓存专项使用开发模块，不能对生产静态网页运行；页面回归可通过 CHECK_WEB_URL 指定网页地址。

## 数据库集成测试

`backend/src/test/` 保留了权限、账号、任务状态、事务、清单规则、审核及复查的有效回归。测试需要 MySQL 和四角色示例数据，包含写操作与附件创建，不能指向正在使用的业务库。

准备一个专门的 MySQL 数据库及附件目录，使用该环境独立检出或复制的项目，在其 `.env` 中设置 DB_URL、DB_USER、DB_PASSWORD、JWT_SECRET、DEMO_ENABLED=true、DEMO_PASSWORD 和 UPLOAD_DIR；确认这些配置均指向独立环境后，运行 `./scripts/Maven.ps1 test -B -ntp`，或使用 `./scripts/Build.ps1` 执行完整验证。Maven.ps1 会读取该检出目录的 `.env`。

## 多角色端到端流程

在上述独立环境启动端口为 8082 的 API，前端 Vite 保持 5173，然后运行：

```powershell
# 自定义示例密码时，需与独立 API 保持一致
$env:DEMO_PASSWORD='你的独立环境初始密码'
npm run test:browser
```

流程脚本只允许 `http://localhost:8082/api`，会创建任务、办理历史并上传附件；还须核对该 API 本身使用独立数据库与上传目录，端口限制不等于数据库隔离。该脚本验证三角色办理、缺项提示、异常取消、审核、两轮整改复查，以及无异常归档。

图片默认使用脚本内置的有效 PNG 测试样本，不读取 `.runtime/uploads` 中的业务照片。若需覆盖真实照片尺寸或格式，可将 FLOW_PHOTO_PATH 指向自己有权使用的 PNG/JPEG 文件；图片仅发送到独立验收 API。

## 报告与维护

浏览器执行时生成 `test-results/`，后端执行时生成 `backend/target/surefire-reports/`，均为可再生成的本机产物，不提交源码；已有报告不是启动条件。

`Reset-Demo.ps1` 会清空业务表，只有明确需要重置独立演示环境时使用。`Cleanup-Uploads.ps1` 默认预览过期孤立附件，加 `-Apply` 才实际删除。它们不会在普通启动或构建时自动执行。

任务模板依赖 `DemoData.java` 和 `demo/seed.json`，即使关闭示例数据初始化也要保留。新增数据结构使用新的 Flyway 迁移文件，不能编辑已执行迁移。
