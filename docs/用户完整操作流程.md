# 用户操作流程

账号由管理员分配。初始化示例账号为 admin、tianbo、zhangsan、lisi；密码以管理员实际提供为准。

## admin · 系统管理员

1. 我的 → 系统管理 → 创建用户 → 填写账号、姓名、角色、启用状态和初始密码 → 保存。需要修改时，输入姓名或账号模糊搜索 → 编辑；新密码留空表示保留原密码。
2. 单位档案 → 新增单位 → 填写单位名称、类型、地址、档案人数说明、建筑与分区、关注等级和状态 → 保存。停用单位保留历史，不能再用于新建任务。
3. 检查任务 → 创建任务 → 选择监管单位、任务来源、关注等级和检查期限 → 指定检查员、审核员、复查员 → 勾选本次检查项目 → 保存。
4. 需要新增检查项目时，在任务表单填写项目名称与检查要求 → 保存项目 → 勾选下发。移除项目不会删除既有任务中的记录。
5. 工作台或检查任务 → 查看任务。卡片显示三类办理人员；任务尚未开始时可在详情“调整分配与期限”，开始后不再提供该操作。
6. 单位档案 → 单位详情 → 展开未闭环风险、关联任务或历史问题。每组默认折叠、最近记录在前，每页 5 条，可分别翻页。

管理员负责维护与监管；审核、复查结论由对应办理人员提交。

## tianbo · 监督检查员

1. 检查任务 → 找到管理员分配的任务 → 查看任务 → 开始检查。
2. 按现场情况逐项选择：
   - 正常 → 填写需要保留的核验记录 → 保存。
   - 异常 → 直接打开问题表单 → 填写所在位置、问题类型、现场事实 → 上传照片 → 保存。已有问题可在对应检查项“修改补充”，不必重复登记。
   - 不适用 → 填写不适用原因 → 保存。
   - 待核验 → 保存待确认事实；核实后改为明确结论。
3. 按页面“待补齐”完成缺项 → 提交人工审核。未检查、待核验、缺少原因或缺少问题事实时不能提交；无需另填场所条件。
4. 如审核退回 → 打开任务 → 按审核意见修改对应问题 → 再次提交人工审核。
5. 任务进入整改中后 → 整改复查 → 登记整改材料 → 填写材料提供人、整改情况说明 → 添加图片或 PDF → 保存。责任单位材料由办理人员代录。

## zhangsan · 审核人员

1. 工作台待审核任务，或检查任务 → 找到自己负责且已提交审核的任务 → 查看任务 → 人工审核。
2. 在同一表单查看每条问题的位置、现场事实和照片，选择结论：
   - 确认问题并下达整改 → 填写问题审核意见、整改要求、责任联系人、整改期限。
   - 退回补充事实 → 填写需要补充的内容。
   - 核验排除 → 填写排除依据。
3. 填写本次审核意见；存在未关联问题的来源线索时，核实后勾选排除。
4. 点击“提交审核结果”。选择退回时按钮为“提交并退回补充”，任务交回检查员；确认的问题进入整改，无问题且线索均已处置则归档。

全部问题和本次总意见一次提交。已确认的问题保留原结论，后续退回不覆盖历史。

## lisi · 复查人员

1. 检查任务 → 打开分配给自己的整改任务 → 整改复查 → 查看问题、整改要求和材料。
2. 若本轮缺少整改材料 → 点击“补充材料并复查” → 在同一表单填写材料提供人、整改情况说明，并添加整改附件。
3. 若已有本轮材料 → 点击“记录现场复查”。也可先用“登记整改材料”保存责任单位提供的材料。
4. 选择合格或不合格 → 填写现场复查事实 → 添加复查附件 → 保存。
5. 不合格 → 继续整改 → 收到新材料后再次复查。旧材料和复查历史保留，每轮单独记录。
6. 全部问题复查合格且关联风险闭环后，任务自动完成。

## 查找任务与历史

- 检查任务：输入单位名称、任务编号或地址搜索；按进行中、已完成、已逾期筛选。进行中包含待检查、现场检查、待审核和整改等未逾期任务。
- 卡片边框：进行中为黄色、已逾期为红色、已完成为绿色；逾期不会同时标为进行中。
- 历史画像：常驻展示已完成任务，按全部、有异常、无异常筛选；按完成时间最近在前。相同单位多次检查以时间及档案中的任务编号区分。
- 查看档案：回看现场记录、问题证据和历史。审核、整改与复查历史默认折叠，展开后按问题发生到解决的时间顺序展示。
- 照片：点击放大，点击图片之外的空白处退出；网页也可按 Esc 返回。整改、复查支持 PNG、JPEG、PDF，单文件不超过 10 MB。
- 我的 → 图片缓存 → 清除缓存：仅清除本设备图片副本，不删除服务器资料。退出登录会清理该账号缓存。

检查员可查看自己分配任务的全部阶段；审核员从待审核阶段可见，退回检查时暂不可见；复查员从整改阶段可见。账号必须处于启用状态。
